<p align="center">

**EnterpriseOps-Agent** is an autonomous **Enterprise Operations & Decision Intelligence Platform** that leverages a **Hierarchical Multi-Agent System (MAS)** to automate operational analysis, executive reporting, enterprise risk assessment, and strategic decision-making.

Powered by **Google Agent Development Kit (GEAP)** and **Gemini 3.5 Flash**, the platform orchestrates specialized AI agents that collaborate over enterprise data stored in **Google BigQuery** through **BigQuery MCP**, and is deployed using **Google Agent Runtime** running on **NVIDIA GPU-backed Google Cloud infrastructure**.

</p>
